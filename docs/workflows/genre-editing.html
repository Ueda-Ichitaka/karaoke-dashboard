Genre editing

Genres come from the #GENRE tag of the song files. A contributor corrects them on the Genres page, the USDX Song Factory writes them into the song files, and the library scan notices. Details: features.md.

Step by step

  1. Library scan

    Reads the #GENRE tag of every song file and stores the genres in song_genres; the Genres page's List, Map and Connections tabs show them.

  2. Contributor or admin

    On the Edit tab (/genres/edit) finds the song, presses Edit, types the genres - the field suggests the library's genres - and Saves. Saving the file's own genres, or Reset, drops the edit.

  3. Dashboard

    The edit is stored in genre_edits and shows on every Genres tab at once.

  4. Edit tab

    Export N edits downloads genre-edits.tsv: per song file of an edited folder its path and the genres. Every export has every open edit.

  5. You

    Save it as the Factory's stack/input/genre-edits.tsv, then ./factory.sh pull-genres --apply and ./factory.sh genres - seconds per song.

  6. You

    Copy each stack/output/genres/<folder>/<song file> into the library folder of the same name, overwriting the song file.

  7. Library scan

    The next scan reads the new #GENRE; the files now name the edit's genres, so the edit ends and drops out of the export.
